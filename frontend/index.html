Formato del CSV

El archivo CSV debe contener las siguientes columnas:

  • check_circle codigo_cups_facturado (obligatorio)
  • check_circle descripcion_servicio_facturado
  • check_circle cantidad_facturada
  • check_circle valor_total
  • info id_prefactura (opcional, para agrupar)
  • info id_atencion (opcional)
  • info numero_documento (opcional)

Rendimiento

El procesamiento por lotes permite:

  • speed Evitar timeouts en archivos grandes
  • memory Optimizar uso de memoria
  • analytics Seguimiento de progreso en tiempo real
